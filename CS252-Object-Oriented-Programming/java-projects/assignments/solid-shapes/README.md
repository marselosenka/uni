# Solid Shapes in Java

This project models 3D geometric solids using OOP principles in java.
demonstrates basic OOP features such as inheritance, polymorphism, encapsulation and also uses file I/O by managing and exporting data.

The program defines a base class SolidShape and subclasses such as Cube, Sphere, and Cylinder. 
A `Drawing` class stores multiple shapes, calculates totals, and can export them to simple JSON files.
