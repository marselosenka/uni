Java coursework for CS252, including individual assignments and a two-phase Lost Cities game project.

## Coursework overview

| Folder | Description |
| --- | --- |
| [Battle simulation](java-projects/assignments/battle-simulation/) | A simulation using characters, weapons, groups, and exceptions. |
| [Encryption](java-projects/assignments/encryption/) | An encryption exercise. |
| [File statistics GUI](java-projects/assignments/file-stats-gui/) | A Swing application for displaying file statistics. |
| [Palindromic](java-projects/assignments/palindromic/) | A palindrome exercise. |
| [Piggy bank](java-projects/assignments/piggy-bank/) | A piggy bank abstract data type and custom exceptions. |
| [Solid shapes](java-projects/assignments/solid-shapes/) | A hierarchy of geometric shapes. |
| [Sudoku](java-projects/assignments/sudoku/) | A Sudoku exercise. |
| [Lost Cities game](java-projects/project/lost-cities-game/) | A Java game project organized into phases A and B, with source code and UML diagrams. |

## Technologies and concepts

- Java and object-oriented programming
- Classes, inheritance, interfaces, and exception handling
- Swing graphical interfaces
- UML diagrams

Several assignment folders contain their own README with more details. The Lost Cities project also includes reports and assets alongside its source code.
