# CS364 Assignment 01

This project is a frontend-only website recreation for the CS364 course assignment. I was given a website and had to recreate it from scratch using HTML and CSS, with the goal of matching the original design as closely as possible.

---

## Overview

This project is a static, single-page website built to replicate a provided reference design. It focuses on frontend development only and reconstructs the layout, structure, and styling of the original website.

### What was the assignment about.

- Recreated the website from a given reference
- Built the page structure using HTML
- Styled the layout with CSS and Bootstrap

---

```text
Assignment01/
??? ex01.html        # Main HTML file

??? README.md        # Project documentation
```

---

## Requirements

To view the website locally, you only need:

- A web browser
- An internet connection for the Bootstrap and Font Awesome CDN links

---

## How to Run

1. Open the file `ex01.html` in a browser such as Google Chrome or Microsoft Edge.
2. Make sure the `images/` folder stays in the same directory as the HTML file.
3. The page should load correctly as a static frontend project.

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5 via CDN
- Font Awesome via CDN
