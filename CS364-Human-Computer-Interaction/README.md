## Overview

The repository is organized into two main parts:

* `01_frontend/` - A frontend-only web application built using HTML, CSS, and Bootstrap.
* `02_mobile-app-ui/` - A Figma mobile app prototype for booking experiences and activities.

## 01_frontend

This folder contains a frontend-only website created for the CS364 class. The project focuses on recreating a provided design using HTML, CSS, and Bootstrap.
