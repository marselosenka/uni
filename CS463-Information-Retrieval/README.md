# CS463 — Information Retrieval

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)

Java coursework exploring text compression, string data structures, and term relevance.

## Coursework overview

| Folder | Description |
| --- | --- |
| [Huffman Coding Algorithm](Huffman-Coding-Algorithm/) | Builds a frequency tree and prefix codes for lossless text compression. |
| [Suffix Trie Node](Suffix-Trie-Node/) | Defines a node structure for a suffix trie used in substring matching. |
| [TF-IDF](TF-IDF/) | Calculates term relevance across text documents. |

Each folder contains Java source code and a short README describing the exercise.

## Technologies and concepts

- Java
- Huffman coding and prefix codes
- Suffix tries and substring matching
- Term frequency and inverse document frequency
