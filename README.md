A collection of coursework organized by course, including projects maintained as separate repositories.

| Course | Subject | Coursework |
| --- | --- | --- |
| [CS252](CS252-Object-Oriented-Programming/) | Object-Oriented Programming | Java assignments and a game project |
| [CS351](CS351-Analysis-and-Design-of-Information-Systems/) | Analysis and Design of Information Systems | Full-stack application with Next.js, NestJS, and MySQL |
| [CS352](CS352-FinalProject/) | Final Project | JSON-like domain-specific language in C++ |
| [CS364](CS364-Human-Computer-Interaction/) | Human-Computer Interaction | Frontend website and mobile UI prototype |
| [CS460](CS460-Database-Management-Systems/) | Database Management Systems | SQL and PL/SQL assignments |
| [CS463](CS463-Information-Retrieval/) | Information Retrieval | Huffman coding, suffix tries, and TF-IDF |
| [HY469 team project](HY469-Team07/) | Team project | Dressing Assistant application |
| [CS548](CS548-Cloud-Native-Software-Architectures/) | Cloud-Native Software Architectures | Docker and Kubernetes coursework |

See each course README for its projects and further details.

CS351, CS352, and HY469 Team 07 are Git submodules. To clone the collection with these projects, run:

```bash
git clone --recurse-submodules https://github.com/marselosenka/uni.git
```
